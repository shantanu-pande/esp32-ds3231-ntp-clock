
# ESP32 DS3231 NTP Clock

[![Hardware License](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

A complete hardware design for a Wi-Fi-synchronized, highly accurate digital clock. This project utilizes an **ESP32-WROOM-1** microcontroller, a **DS3231 Precision RTC**, and a **4-Digit 7-Segment Display** driven via NPN transistor multiplexing.

This repository contains the full EDA schematic, PCB layout files, Bill of Materials (BOM), and base firmware required to fabricate and test the board.

All hardware files are added in the repository.
